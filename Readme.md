## 🏎️ DriveX

> **Find Your Perfect Ride.**

DriveX is a premium, responsive and interactive **car-rental frontend experience** built with **HTML5, CSS3, Vanilla JavaScript and JSON**.

Instead of feeling like a basic rental form, DriveX is designed to feel like a modern automotive product: cinematic imagery, deep navy surfaces, cyan highlights, glassmorphism, micro-interactions and a complete discovery → booking → confirmation journey.

# 🌓 Light & Dark Mode

DriveX supports both **Light** and **Dark** themes.

### ☀️ Light Mode

- Bright surfaces
- Dark readable text
- Clean cards
- Cyan DriveX accents
- Cinematic dark hero

### 🌙 Dark Mode

- Deep navy backgrounds
- Light typography
- Premium dark cards
- Cyan accents
- Cinematic automotive visuals

### Hero Theme Rule

The hero uses a dark photographic background, so hero typography must remain high-contrast in **both themes**.

Light Mode should **not** automatically turn hero text dark.

Suggested hero variables:

```css
--hero-text-primary
--hero-text-secondary
--hero-accent
--hero-overlay
```

This prevents hero content from disappearing over vehicle imagery.

---

- Switch Light ↔ Dark

# ✨ Animation & Interaction System

Animations communicate **hierarchy, feedback and interaction**.

### Page Entrance

```css
opacity: 0 → 1;
transform: translateY(20px) → translateY(0);
```

### Card Hover

```css
transform: translateY(-4px);
```

with subtle shadow / border enhancement.

### Buttons

```css
transform: translateY(-2px);
```

with a soft DriveX cyan glow.

### Images

Use subtle:

```css
transform: scale(1.02);
```

Avoid aggressive zooming.

### Modals

Use:

```text
opacity + scale
```

instead of abrupt appearance.

### Navigation

Active links should have:

- Clear active state
- Smooth transition
- Cyan accent
- Keyboard-visible focus state

# ♿ Accessibility & UX

DriveX should remain enjoyable for users who prefer reduced motion and keyboard navigation.

- Keyboard-friendly interactive controls
- Visible `:focus-visible` states
- Accessible buttons and forms
- Sufficient colour contrast
- Reduced-motion support

Recommended:

```css
@media (prefers-reduced-motion: reduce) {
  /* Reduce parallax, large entrances and continuous motion */
}
```

DriveX follows five principles:
